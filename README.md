# English Games (Primary 3)

Small practice games for P3 English: grammar, vocabulary, editing and comprehension.
All questions and passages are original.

- Static HTML, CSS and JavaScript. No frameworks, no accounts, no tracking, no network requests (CSP `default-src 'self'`).
- Progress is saved only in the browser (localStorage).
- Read-aloud uses pre-recorded clips served from this site (generated text-to-speech), with the device's own voice as a fallback. It can be muted.

Open `index.html` for the list of games.
